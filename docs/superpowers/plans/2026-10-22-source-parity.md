# 网页音源对齐实施计划

**目标：** 桌面端提供官网当前显示的 10 个源，统一使用现有隔离网页请求器；单曲失败如实提示，保留本地收藏和限流队列。

**范围：** 网易云、QQ、酷我、TIDAL、Qobuz、JOOX、B站、Apple Music、YouTube Music、Embeat。Spotify 不在官网当前菜单中，从选择菜单移除，旧歌单仍可请求。Embeat 按官网仅在线播放，不发起自动或手动下载。

**方案：** 复用 WebsiteApi，而非对每个音源另写供应商接口；以共享 JSON 音源表统一菜单、分页、专辑支持及下载能力。官网搜索使用 20 条分页，JOOX 不分页。专辑搜索使用 `types=search_album`。保留 `url_id` 以兼容不同解析 ID。所有官网请求仍计入 RequestGate，成功音频地址按实际格式保存，完整 Range 响应才发布。
