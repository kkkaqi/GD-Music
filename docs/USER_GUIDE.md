## 安装与启动

### 使用 Windows 安装包

前往 [v1.0.8 发布页](https://github.com/kkkaqi/GD-Music/releases/tag/v1.0.8)，在 Assets 中下载以下一种（Source code 是源码压缩包，不是安装包）：

| 文件 | 使用方法 |
| --- | --- |
| `GD-Music-1.0.8-Windows-x64-Setup.exe` | 双击安装，完成后通过桌面或开始菜单的 GD-Music 启动。 |
| `GD-Music-1.0.8-Windows-x64-Portable.exe` | 双击运行，无需安装。 |

两个版本均自带运行环境，不需要单独安装 Node.js。实际文件名中的版本号可能更新；仓库源码和安装包是两种不同的交付内容。

本项目目前主要在 Windows x64 上验证。若遇到中文路径启动异常，可将免安装版放在 `C:\GD-Music` 等英文目录运行。

### 第一次使用

1. 打开应用，在顶部选择音乐源。
2. 输入歌名、歌手或专辑名称，按 Enter 搜索。
3. 点击歌曲播放；点击爱心可加入「我喜欢的音乐」。
4. 点击底部音质选框，选择希望播放和下载的音质。

播放与搜索需要网络；已经完整下载、且匹配当前音质的收藏，可直接读取本地音频。

## 搜索与播放

顶部音源菜单接入网易云、QQ 音乐、酷我、TIDAL、Qobuz、JOOX、哔哩哔哩、Apple Music、YouTube Music 和 Embeat。

- 可用性由对应平台及 GD 音乐台上游接口决定。已接入不代表每首歌都能播放或提供全部音质。
- 开启顶部「专辑」选项后，按专辑方式搜索；哔哩哔哩和 Embeat 不提供这一模式。
- 搜索结果可分页加载，JOOX 与网页一样不提供下一页。
- 首页「华语流行」等卡片是分类搜索入口，不会预先下载该分类全部歌曲；点击后展示该次搜索返回的曲目。

底部播放器提供播放 / 暂停、上一首、下一首、循环模式、音质、进度、音量和队列。点击封面上的展开按钮可进入唱片与歌词播放页；点击左上角向下箭头收起。

播放模式在列表循环、单曲循环、随机播放之间切换。点击播放页中的歌词行，可跳到对应时间。

## 收藏与歌单

### 我喜欢的音乐

点击歌曲或底部播放器的爱心即可收藏，再次点击取消收藏。收藏信息保存在本地，正常退出、重启后保留。

支持下载的收藏会按当前所选音质自动排队下载，包括尚未播放的歌曲。下载进度显示在「我喜欢的音乐」顶部，可点击「重试」或「打开音频文件夹」。

取消收藏后，已经下载的文件仍保留在本地；应用目前没有提供缓存清理界面。

### 我的歌单

- 点击侧栏「我的歌单」旁的加号，新建歌单。
- 在歌曲的「更多」菜单中，可加入队列、设为下一首、添加到歌单、收藏或下载。
- 在侧栏歌单右键菜单中，可重命名、导出 JSON 配置或删除歌单。
- 歌单页面的「导出列表」生成文本清单；需要可重新导入的备份时，请使用歌单右键菜单中的「导出歌单配置」。

## 从网页导入歌单

1. 打开 [GD 音乐台网页](https://music.gdstudio.org/)。
2. 在网页「设置中心」点击「导出歌单配置」，保存 `gdmusic_config_日期.json`。
3. 打开桌面端，点击「我的歌单」旁的导入按钮。
4. 选择刚才导出的 JSON 文件，等待导入结果提示。

导入规则：

| 网页内容 | 桌面端位置 |
| --- | --- |
| 网页收藏 | 合并进「我喜欢的音乐」，按音乐源和歌曲 ID 去重。 |
| 网页播放历史 | 另存为「网页播放历史」歌单。 |
| 网页正在播放列表 | 另存为「网页正在播放」歌单，不替换当前队列。 |
| 网页用户歌单 | 导入为本地歌单；配置只有网易云歌单 ID 时会尝试联网补取。 |

同名歌单会自动追加编号。重复导入不会重复添加同一首收藏，但会追加本地歌单。网页的音质、EQ、账户等设置不随歌单导入。

桌面版也接受自己导出的单歌单 JSON。桌面版导出格式目前不支持反向导入网页。

## 音质与下载

### 五档音质

| 音质选项 | 请求参数 | 含义 |
| --- | --- | --- |
| 标准 · 128K | `128` | 有损音频档位。 |
| 较高 · 192K | `192` | 有损音频档位。 |
| 高品 · 320K | `320` | 有损音频档位。 |
| 16bit 无损 · FLAC | `740` | 请求音源提供这一档无损版本。 |
| 24bit 无损 · FLAC | `999` | 请求音源提供这一档无损版本。 |

选项表示请求目标，实际格式、码率和位深以音源返回的文件为准。选择 24bit，不代表上游一定返回 24bit；例如某首歌可能只返回 16bit FLAC。应用不会把有损音频转换成真正无损。

### 自动下载

- 自动下载范围为「我喜欢的音乐」中支持下载的全部歌曲。
- 每次按当前选择的音质下载，不会自动给每首歌保存五份。
- 切换音质后，会补下对应档位；以前的文件仍保留，各档位分开存储。
- 播放优先匹配当前音质的本地完整文件。当前档位未下载完，即使其他档位已有文件，也可能需要联网解析。
- Embeat 与网页一样仅在线播放，可保存收藏信息，但不加入音频下载队列。

### 手动下载

1. 先在底部音质选框中选择希望下载的档位。
2. 在歌曲上右键，或点击歌曲右侧「更多」，选择「下载」。
3. 等待音频准备完成后，在保存对话框中选择位置。

已有完整缓存时会直接复用。保存时保留实际文件格式，支持 MP3、FLAC、M4A、WebM、OGG、WAV、AAC、APE、AIFF、ALAC 等；文件后缀不统一强制为 MP3。

### 下载为什么会等待

接口有请求频率限制。桌面端按 5 分钟最多 48 次 API 请求调度，并为播放、搜索保留部分额度。一次下载可能涉及音频地址等请求，不能把「一次请求」简单理解为「一首歌曲」。

- 后台逐首下载，完成一次尝试后至少间隔约 8 秒。
- 遇到 HTTP 429 会等待至少 5 分钟，随后自动继续。
- 遇到 503 等临时错误会逐步延长等待，通常为 30 秒至 5 分钟，并遵守服务器返回的等待时间。
- 大文件采用流式写入，不设固定 256MB 上限。传输持续有进度时可继续；连续两分钟无进度才超时，后台随后退避重试。

看到排队或等待倒计时可以保持应用运行，无需反复点击下载。

## 桌面歌词

### 打开、关闭和移动

点击底部「词」按钮打开独立桌面歌词窗口。窗口保持置顶，主窗口最小化后仍可显示。

未锁定时，鼠标移入歌词区域会显示工具栏和背景；移出后仅显示歌词。拖动歌词区域可移动窗口。点击工具栏的叉号关闭歌词窗口。

### 颜色与字号

- 当前正在播放的原文和翻译使用所选高亮颜色，默认绿色。
- 尚未开始的下一句原文和翻译使用灰色。
- 保留清晰描边，提高浅色或深色桌面背景下的辨识度。
- 点击设置按钮，可选择 12、16、20、24、28、32、36、40px 字号，调整背景透明度及当前句颜色。
- 主设置面板固定在右侧，字号子菜单向左展开，避免主面板左右移动。
- 原文和翻译同步缩放，窗口会根据字号和换行自动调整范围，并尽量保持在屏幕内。
- 原生调色板可以超出歌词窗口；鼠标移出不会自动关闭设置。再次点击设置、点击窗口内设置区域以外的位置，或按 Esc 可关闭设置。

位置、字号、颜色和透明度会保存到本地。

### 锁定与解锁

点击小锁可锁定歌词。锁定后背景透明，歌词区域允许鼠标穿透，便于操作下方应用。

解锁有两种方式：

1. 将鼠标移入歌词区域，点击右上角出现的黑色小锁。
2. 在主播放器再次点击底部「词」按钮，先解除锁定。

锁定和未锁定共用同一位置的小锁按钮，按钮背景保持透明。

## 窗口与系统托盘

- 主窗口四边和四角：拖动调整大小。
- 窗口空白区域：拖动移动窗口。
- 按钮、歌曲列表、输入框、进度条、滚动条保留自身交互。
- 最大化时拖动空白区域，会还原窗口并移动。

启动应用后，Windows 系统托盘会注册 GD-Music 图标。若没有直接显示，可点击任务栏右下角的小箭头查看。

右键菜单只有「打开GD-Music」和「退出」：

- 「打开GD-Music」：显示主窗口，最小化时先还原。单击或双击托盘图标也可打开。
- 「退出」：先提交并保存最新本地状态，再关闭窗口、歌词和托盘图标。

右上角主窗口的叉号会退出应用。需要继续后台播放时，请最小化主窗口。

## 本地数据与备份

Windows 默认用户数据目录是：

```text
%APPDATA%\GD Music
```

按 Win + R 输入上面的路径即可打开。这里保留了早期版本使用的目录名 `GD Music`，与桌面显示名 `GD-Music` 不同。

| 文件或目录 | 内容 |
| --- | --- |
| `state.json` | 收藏、歌单、历史、队列、音质与音量等状态。 |
| `desktop-lyrics.json` | 桌面歌词位置和样式。 |
| `audio-cache` | 已完整保存的音频、音质信息和下载临时文件。 |
| `api-cache` | 搜索、音频地址、歌词、封面以及请求额度、冷却记录。 |

备份前正常退出应用，复制 `state.json` 和 `desktop-lyrics.json`。需要保留离线音频时，再复制 `audio-cache`，其体积可能较大。恢复也应在应用退出后进行，先备份原文件，再替换对应内容。

安装版与免安装版默认使用同一用户数据目录；移动免安装 EXE 不会把收藏和音频缓存一起移动。

## 快捷键

主窗口中，输入框和下拉选框内的按键优先用于输入或选择。

| 按键 | 功能 |
| --- | --- |
| Space | 播放 / 暂停。 |
| ← / → | 后退 / 前进 5 秒。 |
| ↑ / ↓ | 音量增加 / 减少 5%。 |
| `/` | 聚焦搜索框。 |
| Esc | 关闭菜单、弹窗、播放页或队列；歌词设置中也可关闭设置。 |
| 键盘媒体键 | 支持播放 / 暂停、上一首、下一首；可能受其他播放器占用影响。 |

## 常见问题

### 收藏重启后会消失吗？

正常退出会保存，重新打开后继续使用同一用户数据目录。删除用户数据目录、切换 Windows 用户或恢复旧备份，会影响显示的收藏。

### 第二次播放一定更快吗？

当前所选音质已经完整下载时，优先读取本地文件。仅收藏了歌曲信息、文件仍排队、切换了音质或音源不支持下载时，仍可能需要网络。

### 选了无损却仍然下载失败？

先区分「排队 / 限流等待」和「失败」；等待中的任务会自动继续。确认网页在相同音源、同一首歌、相同音质下是否能下载，再记录错误提示。

v1.0.8 下载遇到 HTTP 403/410 时会刷新签名地址并重试一次，手动点击失败任务的“重试”也会重新解析；这些请求仍遵守共享限流，已有完整音频不重新下载。上游没有返回可下载地址、服务器不可用或所选音质缺失时，仍可能失败。不要把所有失败都判断为歌曲没有无损版本，可尝试同曲的其他音源，并在反馈中注明错误。详见[审查与修复记录](reviews/2026-10-23-v1.0.7-code-review.md)。

### 下一首直接被跳过，没有自动换源？

v1.0.8 实际媒体加载失败也会触发恢复：先有限刷新同源地址，再按歌名和歌手查找其他音源。所有匹配来源都失败后，有播放意图时才跳到下一首；原本暂停时恢复后仍保持暂停。恢复期间手动选歌或切换音质，旧响应不会覆盖新选择。能否恢复仍取决于上游是否提供可用音频。

### 重启后进度显示正确，点播放却从零开始？

v1.0.8 已修复：启动后首次播放上次歌曲，会在音频元数据就绪后恢复已保存的位置；新选歌曲从头开始。若使用旧版本，请更新；若仍遇到问题，请记录歌曲、音源、音质及保存的进度。

### 网页有歌词，桌面端没有翻译？

先确认歌曲和音源一致。原词及翻译依赖上游返回，并按时间戳对齐；部分歌曲只提供原词，或翻译时间戳不同。桌面歌词中无歌词时会显示歌名或状态提示。

### 桌面歌词锁住后点不到其他应用？

锁定后的歌词正文应当穿透鼠标，仅解锁按钮区域接收点击。可从主窗口点击「词」解锁，再调整位置或关闭歌词。

### 如何查看或清理下载文件？

在「我喜欢的音乐」顶部点击「打开音频文件夹」。需要手动清理时，先退出应用并备份数据；不要删除收藏所在的 `state.json`。移除音频缓存后，仍在收藏列表中的曲目会再次加入自动下载。

### 没有看到托盘图标？

确认当前运行的是包含托盘功能的 v1.0.7 或后续版本，并查看任务栏小箭头内的隐藏图标。退出应用后，图标也会移除。

## 从源码运行与打包

需要 Node.js 22.12 或更新版本，以及首次安装依赖、下载 Electron 所需的网络连接。

```powershell
git clone https://github.com/kkkaqi/GD-Music.git
cd GD-Music
npm ci
npm start
```

也可在安装依赖后使用项目中的 `start.bat`。启动器会按版本把 Electron 运行时准备到 `%LOCALAPPDATA%\GDMusic\runtime`，减少本机中文路径启动问题。

| 命令 | 作用 |
| --- | --- |
| `npm start` | 构建界面，再启动桌面应用。 |
| `npm run app` | 使用已有构建启动；首次运行前需要 `npm run build`。 |
| `npm run dev` | 启动端口 5199 的 Vite 开发服务器。 |
| `npm run dev:electron` | 连接开发服务器；先在另一个终端启动 `npm run dev`。 |
| `npm test` | 运行单元与回归测试。 |
| `npm run test:electron` | 构建并执行隔离的桌面界面、音频、歌词与托盘检查。 |
| `npm run dist` | 构建 Windows x64 安装版和免安装版。 |

打包文件输出到项目 `release` 与桌面 `GD-Music-Release` 文件夹。源码仓库保留构建配置和依赖锁文件；本地依赖、生成的程序包及用户音乐数据不属于源码。

桌面测试使用临时用户目录、本地测试音频和受控接口，不操作实际收藏。它验证程序行为，不代表所有在线音源始终可用。

## 问题反馈

可在 [GitHub Issues](https://github.com/kkkaqi/GD-Music/issues) 提交问题，建议附上：

- GD-Music 版本、Windows 版本。
- 问题发生的页面和具体步骤。
- 歌名、歌手、音乐源、所选音质；下载问题注明网页相同条件是否成功。
- 完整错误文字或相关截图。

提交日志、截图或歌单前，检查并移除个人目录、账户信息和不希望公开的收藏内容。
