# GD-Music v1.0.8

本次修复代码审查发现的 4 个问题。

- **下载重试**：音频服务器返回 HTTP 403/410 时刷新失效链接并重试一次；点击失败任务的“重试”也会重新解析，已有完整音频不会重复下载。
- **播放恢复**：实际媒体加载或解码失败后，先有限刷新同源地址，再按歌名和歌手匹配其他音源。暂停状态恢复后仍暂停；旧恢复结果不会覆盖新歌曲或新音质。
- **断点续播**：启动后首次播放上次歌曲会恢复保存的进度；新选歌曲从零开始。
- **搜索历史**：返回、前进或离开搜索页时使旧请求失效，迟到的结果与错误不再污染其他查询。

Windows x64 用户在下方 Assets 中选择：

- `GD-Music-1.0.8-Windows-x64-Setup.exe`：安装版，双击安装。
- `GD-Music-1.0.8-Windows-x64-Portable.exe`：免安装版，下载后双击运行。
- `SHA256SUMS.txt`：两个 EXE 文件的 SHA-256 校验值。

两个版本均自带运行环境，无需安装 Node.js。GitHub 自动生成的 Source code 压缩包是源码，不是安装包。

验证：125 项单元测试、27 项 Electron 检查通过，包含真实音频续播、解码失败刷新与换源、暂停恢复、原有桌面歌词及托盘退出保存检查。
